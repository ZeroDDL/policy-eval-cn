# 方法选择决策树

八个方法对应八种"数据特征 + 研究问题"组合。判断时先问/先看特征，再查表。

## 三个判别问题（对话问诊用）

**问题 1：政策/处理是怎么分配的？**
- a. 只有一个对象受政策（一个省、一个城市、一个国家）→ 大概率 **SCM**
- b. 按一条连续分数线/门槛划分（录取线、贫困线、年龄门槛、规模红线）→ **RDD**
- c. 一批对象同一时点受处理 → **DID**（若两组基线特征差异大 → **PSM-DID**）
- d. 一批对象但**不同时间**分批受处理 → **多期 DID 起步，诊断后可能升级稳健估计量**
- e. 处理不是"有/无"，而是**程度/剂量不同**（补贴比例、减排强度）→ **强度 DID**
- f. 没有面板，只有截面，且两组特征差异明显 → **PSM**

**问题 2：数据是什么结构？**
- 单个时点截面 → 只能 PSM 或 RDD（有门槛时）
- 面板/重复截面（多期）→ DID 家族或 SCM

**问题 3：有没有干净的对照？**
- 完全没有对照且只有一个处理对象 → SCM（用供体池合成对照）
- 有对照但特征不可比 → PSM 或 PSM-DID
- 全体同时受处理、无对照 → 八法均不适用，提示用户换研究设计（如寻找外生变异）

## 拿不准时的兜底原则

1. 交错时点一律先跑 `bacondecomp` 诊断：坏比较权重低 → TWFE 可用；权重高 → 升级稳健估计量。
2. 截面两期 + 基线失衡 → 先 PSM 再 DID。
3. 用户只有"相关性"问题、没有政策冲击 → 不做因果断言，提示改用描述性/相关性分析。
