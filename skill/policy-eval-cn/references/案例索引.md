# 案例索引：变量约定、替换方法、诊断清单

案例库 = 8 个文件夹，每个含 `XX案例代码.do`（模板）+ `XX案例数据.dta`（模拟数据）+ log 与输出图表。

**实战模式通用替换法**：复制模板 do 到输出文件夹 → 删除/注释"模拟数据段"（模板中以 `set seed` 开头、`save "XX案例数据.dta"` 结束的段落）→ 替换为下面的"标准变量构造块"（变量名按用户数据实际映射，先向用户确认）→ 后续分析代码不动。

## 1. DID（DID案例-08-14）

- **标准变量**：`id`（个体编号）、`year`（年份）、`y`（结果变量）、`treat`（处理组=1）、`post`（政策后=1）、`did`（=treat×post）、`x1 x2`（控制变量，可选）
- **需向用户确认**：个体变量、年份变量、结果变量、哪些个体算处理组、政策年份、控制变量
- **构造块示例**：
  ```stata
  use "用户数据.dta", clear
  clonevar id = 企业编号
  clonevar year = 年份
  clonevar y = 结果变量
  gen treat = <处理组条件>
  gen post = (year >= 政策年)
  gen did = treat * post
  xtset id year
  ```
- **诊断清单**：事件研究图政策前系数不显著（平行趋势）；安慰剂检验经验 p 值 < 0.1；log 中 `>>>` 标记行给出真实/估计系数
- **产出**：DID基准回归结果.rtf、平行趋势检验图.png、安慰剂检验_散点图.png、安慰剂检验_核密度图.png

## 2. PSM（PSM案例-08-15）

- **标准变量**：`train`（处理=1，可改名但模板全文用 train）、`lnwage`（结果变量）、协变量 `age edu married city`
- **需向用户确认**：处理变量、结果变量、进入倾向得分模型的协变量（应丰富、且不受处理影响）
- **构造块示例**：
  ```stata
  use "用户数据.dta", clear
  clonevar train = 处理变量
  clonevar lnwage = 结果变量
  clonevar age = ...   // 协变量按实际映射，个数可增减，
                       // 但模板中 psmatch2 语句的协变量列表要同步改
  ```
- **诊断清单**：匹配后各协变量标准化偏差 < 10%；共同支撑图两组分布重叠充分；朴素 OLS 系数与匹配后 ATT 的差异（纠正了多少选择偏差）
- **产出**：PSM回归结果.rtf、平衡性检验_标准化偏差图.png、共同支撑_倾向得分分布图.png

## 3. RDD（RDD案例-08-16）

- **标准变量**：`x`（驱动变量，**已减去门槛值**，断点在 0）、`d`（=x≥0）、`lnwage`（结果变量）、协变量 `age edu`（可选）
- **需向用户确认**：驱动变量（连续的分数/年龄/规模等）、门槛值、结果变量、断点两侧样本量是否充足
- **构造块示例**：
  ```stata
  use "用户数据.dta", clear
  gen x = 驱动变量 - 门槛值
  gen d = (x >= 0)
  clonevar lnwage = 结果变量
  ```
- **诊断清单**：rdplot 断点处肉眼可见跳跃；rddensity 密度检验 p > 0.1（无精确操纵）；协变量在断点处连续；更换带宽结果稳定
- **首次运行注意**：rddensity 安装必须 `ssc install rddensity, all replace`（见 stata批处理.md 坑 4）
- **产出**：RD图_断点跳跃.png

## 4. SCM（SCM案例-08-17）

- **标准变量**：`id`（地区/单元编号）、`year`、`y`（结果变量）、`x`（不随时间变化的预测变量，可多个）；模板中 `trunit()`=处理单元编号、`trperiod()`=政策年
- **需向用户确认**：处理单元是哪一个（唯一）、政策年、供体池范围（哪些单元从未受政策影响且不受溢出）、预测变量
- **构造块示例**：
  ```stata
  use "用户数据.dta", clear
  clonevar id = 省份编号
  clonevar year = 年份
  clonevar y = 结果变量
  clonevar x = 预测变量
  xtset id year
  * 同时把模板 synth 语句里 trunit(1) trperiod(2016) 改成实际值
  ```
- **诊断清单**：政策前 RMSPE 小（合成拟合好）；路径对比图政策前高度重合；安慰剂检验（in-time/in-space）中处理单元效应显著大于安慰剂
- **产出**：SCM_路径对比图.png、SCM_处理效应路径.png、SCM_安慰剂检验图.png、SCM_intime检验图.png

## 5. PSM-DID（PSMDID案例-08-18）

- **标准变量**：`id`、`year`、`y`、`treated`（处理组）、`post`（政策后）、匹配协变量 `size firmage lev`（用政策前取值）
- **需向用户确认**：除 DID 常规项外，确认用于匹配的政策前协变量
- **诊断清单**：匹配后平衡性（标准化偏差图）；共同支撑；匹配样本上 DID 的事件研究图政策前不显著；朴素 DID 与 PSM-DID 结果对比
- **产出**：PSMDID回归结果.rtf、平衡性检验图.png、共同支撑图.png、事件研究图.png

## 6. 多期 DID（多期DID案例-08-19）

- **标准变量**：`id`、`year`、`y`、`E`（首次处理年份，**从未处理 = 0**）、`did`（=(E>0)&(year>=E)）、`exp`（处理年限）
- **需向用户确认**：每个个体的首次处理年份（或政策批次）、从未处理者如何标识
- **构造块示例**：
  ```stata
  use "用户数据.dta", clear
  clonevar id = ...; clonevar year = ...; clonevar y = ...
  gen E = <首次处理年份; 从未处理=0>
  gen did = (E > 0) & (year >= E)
  gen exp = (year - E + 1) * did
  xtset id year
  ```
- **诊断清单**：`bacondecomp y did, ddetail` 中"晚 vs 早"坏比较的权重——权重低 TWFE 可信，权重高（经验法则 >20%）→ 升级案例 7 稳健估计量；事件研究政策前系数不显著
- **产出**：多期DID_事件研究图.png

## 7. 交错 DID 稳健估计量（交错DID案例-08-20）

- **标准变量**：同案例 6（`id year y E did exp`）
- **两个语法陷阱**（模板注释里也有，务必保持）：
  - `csdid` 的 `gvar(E)`：**0 表示从未处理**；
  - `did_imputation` 的首次处理变量：**从未处理者取缺失值**（模板用 `gen Ei = E if E > 0`），与 csdid 约定恰好相反；
  - `eventstudyinteract` 的 `control_cohort()` 接受**指示变量**而非常数（模板先生成 `never` 变量）
- **诊断清单**：CS 的 `estat event` 政策前系数不显著；CS / Sun-Abraham / Borusyak 三套结果相互接近（互证）；与 TWFE 的差距说明偏误大小
- **产出**：交错DID_事件研究对比.png
- **扩展**：平行趋势敏感性分析可用 `honestdid`（接在 `estat event` 后，`pre()`/`post()` 填系数在 e(b) 中的位置），模板未含，用户需要时参考稳健DID案例-08-22 的 do 文件

## 8. 强度 DID（强度DID案例-08-21）

- **标准变量**：`id`、`year`、`y`、`treated`、`dose`（处理强度，未处理=0）、`post`、`dose_post`（=dose×post）
- **需向用户确认**：强度变量的含义与量纲（补贴比例？减排强度？）、零强度者是否为干净对照
- **诊断清单**：强度分布图（零强度组存在且占比合理）；分档剂量-反应曲线单调性；log 中 `>>>` 行给出 ATT_glob 参考值
- **产出**：强度DID_强度分布图.png、强度DID_剂量反应图.png

## 案例库获取方式

- 本机（作者环境）：案例库位于公众号归档目录下的 8 个 `*案例-08-*` 文件夹，`config.txt` 的 `cases=` 指向该目录。
- 读者环境：从 GitHub 仓库 `policy-eval-cn` 的 `cases/` 目录下载（仓库地址见系列收官推文），解压后把 `cases=` 指向解压位置。
