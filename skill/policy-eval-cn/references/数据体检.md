# 数据体检：扫描用户数据判断结构

## 用法

用户提供了数据文件（`.dta` / `.csv` / `.xlsx` / `.xls`）但说不清结构时：

1. `.csv` 可直接用 Read 工具查看前几行与列名；
2. 其他格式用 Stata 探针。把 `scripts/数据体检.do` 复制到一个**可写的工作目录**（如用户数据所在文件夹），用 PowerShell 运行：

```powershell
Start-Process -FilePath '<Stata路径>' -ArgumentList '/e','do','数据体检.do','"<数据文件完整路径>"' -WorkingDirectory '<可写目录>' -Wait -PassThru
```

3. 运行结束后读取工作目录下的 `数据体检.log`，按下述规则判别。

## 探针输出内容

- 全部变量清单（名称/类型/标签）
- 数值变量摘要统计（均值/极值）
- 取值个数 ≤ 12 的变量的完整分布（用于识别处理变量、年份变量、组群变量）

## 判别规则

**是否面板**：存在一个取值个数很多的 id 类变量 + 一个年份/期数变量，且观测数 ≈ id 数 × 年份数。探针无法自动 `xtset`，需要你看变量清单与分布推断；拿不准就问用户"这份数据里每家企业/每个人是不是有多年观测？"

**处理形态**：
- 0/1 二值变量 → DID 家族或 PSM；
- 连续取值且含 0 → 强度 DID 候选（向用户确认该变量是否是"政策强度/剂量"）；
- 没有处理变量但有连续变量 + 用户提到分数线/门槛 → RDD 候选（需确认门槛值）。

**处理时点**：若有"首次处理年份"类变量或处理变量随时间从 0 变 1：
- 全部处理者同一年开始 → 统一时点 DID / PSM-DID；
- 不同处理者不同年份开始 → 交错处理 → 多期 DID 起步 + Bacon 诊断。

**处理单元数**：处理变量为 1 的 id 只有一个（或极少）→ SCM 候选（需确认有足够多的未处理供体与较长政策前时期）。

## 判完要做什么

把判别结论按 references/决策树.md 映射到方法，用一句话向用户说明："你的数据是 XX 结构，政策是 XX 分配方式，适合用 XX 方法，因为……"。然后进入 SKILL.md 第 3 步套模板。

## 注意

- 数据文件路径含中文或空格时，传给 Stata 的参数务必整体加双引号。
- 探针只读数据、不写回，安全。
- 若 Stata 运行失败且 log 未生成，先检查 -WorkingDirectory 是否可写（不能在 Program Files 下）。
